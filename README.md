# snyk-marketing/homebrew-tap

Homebrew casks for tools from [snyk-marketing](https://github.com/snyk-marketing).

```sh
brew install snyk-marketing/tap/aiseceng
```

| Cask | What it is |
| :-- | :-- |
| [`aiseceng`](https://github.com/snyk-marketing/aiseceng-cli) | The AI Security Engineers community, from your terminal |

Casks here are written by each tool's release workflow ([GoReleaser](https://goreleaser.com)), so edit them in the tool's repo, not here.
